# 06 - Fotografías y Videos

Evidencia visual del funcionamiento del prototipo Ball and Beam.

### Contenido Sugerido:
* **Montaje Físico:** Fotos del sistema de medición y actuadores.
* **Videos de Funcionamiento:** Pruebas de estabilización en referencia fija y seguimiento de al menos dos cambios de referencia.
* **Evidencia de Sustentación:** Registro del prototipo operando de forma estable y repetible.
