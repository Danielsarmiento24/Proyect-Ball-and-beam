# 02 - Especificaciones Técnicas del Montaje
Documentación necesaria para la reconstrucción del experimento[cite: 227].

### Secciones:
* **Lista de Materiales:** Actuadores (servos), sensores y componentes electrónicos.
* **Diagramas Eléctricos:** Esquemas de conexión y pinout detallado.
* **Planos y Dimensiones:** Medidas físicas de la viga y especificaciones de la esfera.
* **Condiciones de Operación:** Límites físicos del carril y recomendaciones de seguridad para evitar riesgos eléctricos o mecánicos.
