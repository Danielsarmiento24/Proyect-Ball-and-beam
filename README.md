# 03 - Códigos del Proyecto

Software organizado y comentado para su revisión y reutilización.

### Estructura de Subcarpetas:
* **Adquisicion_Datos/:** Implementación de filtros (si aplica) y rutinas de lectura de sensores.
* **Identificación/:** Scripts para procesamiento de datos y estimación de parámetros.
* **Simulacion/:** Modelos numéricos para comparación con la respuesta experimental.
* **Controladores/:** Código fuente de la ley de control implementada en el hardware.
